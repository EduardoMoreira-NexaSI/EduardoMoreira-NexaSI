### NOUMENON — Computational Laboratory of Quantum Worlds and Observers

An academic computational research project investigating how observers with limited access to a simulated world's dimensions can **observe, store information and infer hidden structure**.

The project explores questions involving:

- multidimensional computational worlds;
- limited observers;
- hidden dimensions;
- observation and projection;
- inference from incomplete information;
- multi-agent systems;
- computational modeling;
- mathematical representation of systems.

The current work is focused on strengthening the project's mathematical and computational foundations, especially through **linear algebra, vectors, matrices, probability and scientific computing**.

> Core idea: move from philosophical questions to explicit mathematical models, algorithms and reproducible computational experiments.

**Current technologies:** Python · Object-Oriented Programming · Dataclasses · Computational Modeling

[View NOUMENON repository →](https://github.com/EduardoMoreira-NexaSI/noumenon)
